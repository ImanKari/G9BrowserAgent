      Two engines, one tool layer
      
              
        This extension is Engine 1: agents drive the tabs of this browser. Engine 2 is a
        browser the daemon launches in the background — for unattended runs and for tabs
        you send there. Both run the same tools, and the daemon keeps each tab to one agent
        at a time.
